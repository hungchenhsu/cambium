# ADR-0019: A thin command-line client

- **Status:** Accepted
- **Date:** 2026-11-10

## Context

Phase 1b adds a CLI. [ADR-0004](0004-agent-first-interfaces.md) makes it a thin
client over the API: it may not offer features the API cannot express.
[ADR-0005](0005-internationalization.md) requires message catalogs for human
output from the first string, names Project Fluent as the leading candidate, and
keeps machine output untranslated. [ADR-0003](0003-licensing.md) makes clients
Apache-2.0, so the CLI cannot depend on the AGPL server crates.

The `cambium` binary already exists: it runs the server and holds host-local
administration such as `admin bootstrap`, which needs the data directory, not
the API.

## Decision

- **Crate and binary.** A new Apache-2.0 crate `cambium-cli` builds the binary
  `cambium-cli`. Both are renamed with the product. It depends only on
  `cambium-protocol` and permissively licensed crates.
- **One generic command per API call.** `cambium-cli call <operation>` sends
  `POST /v1/operations/<operation>` with a JSON object read from `--input`, from
  a file (`--input @path`), or from standard input (`--input -`). The server
  validates the input, so the CLI never needs a release for a new operation.
  `--idempotency-key` sets the `Idempotency-Key` header.
- **Discovery from the server.** `cambium-cli operations` lists the operations
  and their input schemas from the server's MCP `tools/list`, the same source
  of truth as MCP clients.
- **Credentials.** The token comes from `CAMBIUM_TOKEN` or from a file named by
  `--token-file`, never from a command-line argument, which other local users
  can read in the process list. The URL comes from `--url` or `CAMBIUM_URL`,
  with `http://127.0.0.1:8080` as the default. This version speaks plain HTTP;
  TLS support is a separate decision, because it adds a cryptography dependency
  that the license allow-list must cover.
- **Machine output.** With `--json`, standard output is exactly the API's JSON
  response body, for success and failure alike, on one line. Nothing on standard
  output depends on locale. Exit status: `0` success, `1` API error, `2` usage
  error, `3` the server could not be reached or answered with something other
  than an API response.
- **Human output.** Without `--json`, the CLI prints the response as indented
  JSON, and errors and notices as messages from a Fluent catalog compiled into
  the binary. `en` is the only catalog in this version. The locale never
  changes standard output with `--json`.

## Consequences

- The CLI covers every operation from its first release, and new operations need
  no CLI change.
- Typed subcommands, such as `repo create`, can be added later as sugar over
  `call`, but they may not add behavior.
- The CLI cannot reach an HTTPS endpoint until the TLS decision is made.
- A Traditional Chinese catalog can be added without changing code.
