# Security policy

## Supported versions

Cambium is pre-alpha and has no releases yet. Security fixes land on `main`.

## Reporting a vulnerability

Report vulnerabilities privately through GitHub's private vulnerability reporting:

<https://github.com/hungchenhsu/cambium/security/advisories/new>

Do not open a public issue, pull request, or discussion about a vulnerability.

Include:

- the affected component and commit
- steps to reproduce
- the impact, for example data exposure, data loss, or cross-tenant access

We will acknowledge your report as soon as we can, keep you updated while we work on a fix, and credit you in the advisory unless you ask us not to.
